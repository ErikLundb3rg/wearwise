After going to many late-night talks and chatting with sponsors for inspiration, our group decided we wanted to incorporate AI in some way into our project. From a spark of inspiration, we decided to create an app that creates outfits not only based on style but with an additional twist -- an outfit that incorporates your wardrobe and the weather. We started by writing out the app's functionality and creating draft sketches of our UI.

Finally came implementation time, and two of the sponsors stood out to us: Groq and Convex. Right away we ran into a problem: none of us had previously used Convex. Furthermore, we faced many installation challenges. Some of us didn't have VS Code and others didn't have Git. It took time for all of us to get on the same page, but eventually, we were able to start creating our project.

We are very proud to have been able to work with Convex and implement Groq. Although we could not do as much as we wanted, this project could go a lot further into the future. An example could be syncing the app with your daily schedule and getting personalized recommendations based on planned events (i.e., a meeting, workout, wedding, etc.). Expanding on this, eventually, we could have the program recommend clothing to pack for a trip based on your itinerary and the destination's predicted weather. We could also implement ads from companies the user has shown to like over time.
